## Cleaning rules applied to every output

- snake_case column names. Text is Unicode-normalised (NFC), whitespace is collapsed and trimmed (e.g. `'Total - Dwelling condition '` → `'Total - Dwelling condition'`).
- Thousands separators are removed and numeric columns are stored as numbers.
- Government missing or suppression markers become NaN. The original cell is kept in `raw_value` and its meaning in `value_status` / `value_flag`. An unrecognised marker stops the run.
- Reliability and quality indicators are kept in their own columns, never merged into values.
- Only exact duplicate rows are removed, and the count is reported (0 in every output this run).
- Every Excel parser checks the sheet's header cells first, and stops if the layout differs from the one inspected.
- Datasets are not joined.
