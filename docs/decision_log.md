Design and data decisions made during the project, newest last. Each entry records what was decided, what else was considered, and why. The date is when the decision was first committed; the linked document has the full reasoning.

Add a new row at the end when a decision is made or changed; never edit an old row's decision. If a decision is reversed, add a new entry that says which one it replaces.
